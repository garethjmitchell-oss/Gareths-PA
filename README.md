# Gareth's PA

A personal assistant for ADHD brains, powered by Claude. Inspired by [Goblin Tools](https://goblin.tools).

No app to install. No code to run. Just paste the system prompt into a Claude Project on your phone, and you've got 8 tools in your pocket.

## Setup (takes 2 minutes)

1. Open the **Claude app** on your phone
2. Tap the **menu** (top-left) and go to **Projects**
3. Create a **new project** — call it whatever you like ("PA", "Tools", "Brain Help")
4. Tap **Set custom instructions**
5. Open the file `system-prompt.md` in this repo
6. **Copy everything below the dotted line** in that file
7. **Paste it** into the custom instructions box
8. Save, start a new conversation in that project, and you're done

Every conversation you start in that project will have your PA ready to go.

## The 8 Tools

| # | Tool | What it does |
|---|------|-------------|
| 1 | **Magic ToDo** | Breaks a task into small, actionable steps |
| 2 | **Formalizer** | Rewrites text in a different tone |
| 3 | **Judge** | Reads the emotional vibe of a message |
| 4 | **Estimator** | How long will this take? (ADHD-adjusted) |
| 5 | **Compiler** | Organises a brain dump into action items |
| 6 | **Professor** | Explains something simply |
| 7 | **Consultant** | Helps you decide (always gives a recommendation) |
| 8 | **Chef** | What can you cook with what you have? |

## How to Use

- **Pick by number:** Type `1` then your task, or just `1` and it'll ask
- **Pick by name:** `todo clean the house` or `judge is this email rude?`
- **Just talk:** Claude will figure out which tool you need
- **Adjust detail:** Say "more detail" or "less detail" anytime
- **Get unstuck:** Say "just start" or "help me start" for one-step-at-a-time mode
- **See the menu:** Say "menu" or "help"

## ADHD-Friendly Features

- All output is short, scannable, and uses bullet points
- Task lists mark the easiest step with a star (quick win)
- Time estimates include "with breaks" because you will take breaks
- The Compiler separates your thoughts into DO / REMEMBER / DECIDE
- Overwhelm detection — if you're spiralling, it'll catch it and offer one tiny step
- "Just start" mode walks you through tasks one micro-step at a time
- Never more than 3 options at once
- Always a recommendation — never "it depends"
