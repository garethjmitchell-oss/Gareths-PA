# Gareth's PA

A personal assistant for ADHD brains, powered by Claude. Inspired by [Goblin Tools](https://goblin.tools) and extended with research-backed tools for high-functioning neurodivergent adults.

No app to install. No code to run. Just paste the system prompt into a Claude Project on your phone, and you've got 13 tools in your pocket.

## Setup (takes 2 minutes)

1. Open the **Claude app** on your phone
2. Tap the **menu** (top-left) and go to **Projects**
3. Create a **new project** — call it whatever you like ("PA", "Tools", "Brain Help")
4. Tap **Set custom instructions**
5. Open the file `system-prompt.md` in this repo
6. **Copy everything below the dotted line** in that file
7. **Paste it** into the custom instructions box
8. Save, start a new conversation in that project, and you're done

Every conversation you start in that project will have your PA ready to go.

## The 13 Tools

| # | Tool | What it does |
|---|------|-------------|
| 1 | **Magic ToDo** | Breaks a task into small, actionable steps |
| 2 | **Formalizer** | Rewrites text in a different tone |
| 3 | **Judge** | Reads the emotional vibe of a message (with RSD filter) |
| 4 | **Estimator** | How long will this take? (ADHD-adjusted, with context-switching cost) |
| 5 | **Compiler** | Organises a brain dump into DO / REMEMBER / DECIDE |
| 6 | **Professor** | Explains something simply |
| 7 | **Consultant** | Helps you decide — always gives a recommendation |
| 8 | **Kickstart** | Overcomes the emotional wall stopping you from starting |
| 9 | **Spotter** | What should I work on right now? (matched to your energy) |
| 10 | **Shields Up** | Processes criticism, rejection, and RSD without spiralling |
| 11 | **Copilot** | Preps for meetings and hard conversations; extracts actions after |
| 12 | **Debrief** | Quick end-of-day reflection — wins, friction, tomorrow's focus |
| 13 | **Pause** | Emergency circuit breaker for overwhelm and shutdown |

## How to Use

- **Pick by number:** Type `1` then your task, or just `1` and it'll ask
- **Pick by name:** `todo clean the house` or `shields up my manager criticised me`
- **Just talk:** Claude will figure out which tool you need
- **Adjust detail:** Say "more detail" or "less detail" anytime
- **Get unstuck:** Say "just start" or "help me start" for one-step-at-a-time mode
- **See the menu:** Say "menu" or "help"

## ADHD-Friendly Features

- All output is short, scannable, bullet points — designed for a phone screen
- Task lists mark the easiest step with ⭐ and put it first for momentum
- Time estimates include "with breaks" because you will take breaks
- Context-switching cost is included in time estimates
- The Compiler separates thoughts into DO / REMEMBER / DECIDE
- Judge includes an RSD filter — a charitable reread of any message
- Consultant checks your gut first, and always gives a recommendation
- Magic ToDo detects emotionally loaded tasks and suggests a dopamine primer
- Kickstart specifically targets the "Wall of Awful" — the emotional barrier, not just the task size
- Spotter matches tasks to your energy level so you don't fight your brain
- Shields Up handles rejection sensitivity with validation before advice
- Copilot externalises meeting prep so working memory doesn't have to hold it
- Debrief takes under a minute and makes sure wins get registered
- Pause grounds you first, never launches into productivity advice during a crisis
