# Tool 5: Compiler

## Purpose
Transforms messy, unstructured brain dumps into organised, actionable items.

## Why It Matters for ADHD
ADHD brains often think in tangles — ideas, worries, tasks, and random thoughts all mixed together. Getting things OUT of your head is step one. But a messy dump is still overwhelming. The Compiler untangles it into clear categories so you know what to actually DO.

## Triggers
`5`, `compile`, `organise`, `organize`, `brain dump`, `dump`

## Input
Unstructured text — stream of consciousness, messy notes, voice-to-text rambling, bullet fragments, anything.

## Output Format
Separate into three categories:
- **Things to DO** — action items with checkboxes `- [ ]`
- **Things to REMEMBER** — information to keep, no action needed
- **Things to DECIDE** — open questions that need a choice

Within each category, group by theme if multiple topics are detected. Each action item must be concrete and specific.

## Detail Levels
| Level | Behaviour |
|-------|-----------|
| Less detail | Just the bare action item list, no categories |
| Default | Three-category breakdown, grouped by theme |
| More detail | Categories + priority markers + suggested sequence |

## ADHD Adaptations
- The three-category split (DO / REMEMBER / DECIDE) is critical — these are different cognitive modes and mixing them causes overwhelm
- Action items are concrete: "Email Sarah about the report deadline" not "Deal with work stuff"
- If the dump reveals overwhelm, don't just list everything — highlight the ONE most urgent item

## Example

**Input:** `5 ok so I need to call the dentist but I keep forgetting and also mum's birthday is next Thursday I think or maybe Wednesday need to check and the car needs an MOT soon and I should probably start looking at flights for summer holiday oh and I ran out of coffee and the boiler is making a weird noise again`

**Output:**

### Things to DO
- [ ] 1. **Call the dentist** to book an appointment
- [ ] 2. **Check mum's birthday** — is it Wednesday or Thursday?
- [ ] 3. **Buy coffee**
- [ ] 4. **Book the car in for an MOT**
- [ ] 5. **Look at summer flights** (no rush — just start browsing)
- [ ] 6. **Call a plumber** about the boiler noise

### Things to REMEMBER
- Mum's birthday is next week (confirm the day)
- Car MOT is due soon

### Things to DECIDE
- Where to go for the summer holiday (before booking flights)

*Want me to break any of these down further?*
